# Опись: движок — что сохраняется у актёра

### Серверная сущность актёра (CSE_ALifeCreatureActor, в .scop)
| Что | Где | Категория | Сейчас |
|---|---|---|---|
| Позиция, уровень, вершины графа | CSE_Abstract / CSE_ALifeObject | ЛИЧНОЕ | уже из записи персонажа на сервере |
| Здоровье | CSE_ALifeCreatureAbstract::fHealth | ЛИЧНОЕ | уже из записи персонажа |
| Деньги | CSE_ALifeTraderAbstract::m_dwMoney | ЛИЧНОЕ | уже из записи персонажа |
| Фракция | m_community_index | ЛИЧНОЕ | уже из записи персонажа (`keep_faction`) |
| Ранг, репутация | m_rank, m_reputation | ЛИЧНОЕ | **мастера** |
| Имя, профиль, иконка | m_character_name_str, m_sCharacterProfile, m_SpecificCharacter | ЛИЧНОЕ | имя ставится из профиля; профиль и иконка — мастера |

### Клиентские данные актёра (client_data той же сущности: CActor::save)
| Что | Где | Категория |
|---|---|---|
| Здоровье, выносливость, радиация, кровотечения, раны, пси | CEntityCondition | ЛИЧНОЕ |
| Сытость, алкоголь, действие лекарств, бустеры | CActorCondition | ЛИЧНОЕ |
| Активный слот, стартовый диалог, игровое имя, деньги | CInventoryOwner, CCharacterInfo | ЛИЧНОЕ |
| Фильтры карты ПДА, предметы быстрого доступа (4 слота) | CActor::save | ЛИЧНОЕ |

Всё это — один блок данных актёра; его можно хранить на сервере целиком и подставлять своему актёру при загрузке (до появления актёра в игре).

### Реестры A-Life (в .scop), под каким id
| Реестр | Ключ | Что | Категория |
|---|---|---|---|
| Инфопоршни | id владельца (актёр — 0; у NPC свои, редко) | сюжетные и прочие флаги | ЛИЧНОЕ, кроме «фактов о мире» (инструменты техников и т. п.) |
| Отношения | id персонажа | у записи актёра (0): отношение группировок к игроку и личные отношения актёра; у записей NPC — их личное отношение к актёру (NPC → 0) | ЛИЧНОЕ: запись 0 и все «→ 0» в записях NPC |
| Задания | 0 | весь список заданий игрока со стадиями | ЛИЧНОЕ |
| Новости ПДА | 0 | лента сообщений | ЛИЧНОЕ |
| Статистика | 0 | движковая статистика актёра | ЛИЧНОЕ |
| Метки карты | 1 (весь менеджер карты) | все постоянные метки: задания, тайники, пользовательские, NPC | ЛИЧНОЕ (это карта игрока); общие метки (тайники) уже рассылаются событиями и заново ставятся у каждого |
| Профили NPC | имя профиля | какие уникальные профили уже использованы | МИР |

### Наше (кооп)
| Что | Где | Категория |
|---|---|---|
| Посещённые точки быстрого перемещения | локальный файл в папке профиля (`coop_travel`) | ЛИЧНОЕ — перенести в личный прогресс на сервере (сейчас не откатывается с миром и не переезжает на другой ПК) |
| Группа | сервер | ЛИЧНОЕ (уже на сервере) |
| Вещи игрока | «тень» игрока в мире + запись персонажа | ЛИЧНОЕ (уже) |
